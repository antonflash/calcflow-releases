# CALCFLOW

Мінімалістичний калькулятор для Windows 11 у стилі [TIMEFLOW](https://github.com/antonflash/timeflow-releases): темне скло, великі цифри й салатове світіння результату.

## Завантаження

Остання версія лежить у [Releases](https://github.com/antonflash/calcflow-releases/releases/latest), файл `CALCFLOW-Setup-X.Y.Z.exe`.

У цьому репозиторії тільки інсталятори, вихідний код закритий.

## Встановлення й оновлення

Програма ставиться в профіль користувача, права адміністратора не потрібні. Інсталятор не підписаний, тому Windows SmartScreen може показати вікно «Windows захистила ваш ПК». Щоб продовжити, натисніть «Докладніше», а потім «Виконати в будь-якому разі».

Нові версії CALCFLOW завантажує сам. Коли оновлення готове, зліва вгорі, поруч із шестернею, з'являється зелена іконка. Клік по ній показує, що змінилося, і пропонує оновитися зараз. Якщо відмовитися, оновлення встановиться під час закриття програми.
